# TopBar

The thin mono line above every screen: navigation on the left, context on the right.

- Browsing: the same bar on an `ink` band across the full width, with `on-ink` text and **BROWSING** in `on-ink-accent` before the position counter. It is the only screen with a filled bar, so browsing can't be mistaken for studying.
- Study screen: breadcrumb "Decks / *deck*" left (both parts tappable), the **position counter** "3 / 12" right in `ink`, tabular figures.
- Other screens: a back link ("← Decks", "← Boxes") left and the screen or deck name right.
- `tally` style: 11px mono, uppercase, `mute`, with the current item in `ink`.

The deck list has no top bar: its header is the wordmark with a **⋯** button on the right (see Menu).

Watch: only the position counter.
