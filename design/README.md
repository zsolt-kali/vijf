# Design

Everything vijf looks like comes from one design system, shared by the web app, the iPhone app,
the Apple Watch app and its complication.

| File | What | Used by |
|---|---|---|
| `tokens.json` | Colours (light and dark), type styles, spacing, borders, sizes | The web app's CSS (`web/index.html`) and `apple/VijfKit/Sources/VijfKit/Tokens.swift` (generated by `apple/scripts/generate_tokens.py`). Tests fail if either drifts. |
| `brand.md` | The brand book: wording, colour meanings, type, shape, motion, icons, and how each platform applies them | Anyone changing how something looks or reads |
| `components/*.md` | Guidelines for the seven components: Button, StudyCard, TopBar, BoxRow, DeckRow, Field, Toast | Building or changing a screen |

The design system itself, with live component previews, and the screen mockups live on
claude.ai (private to the owner):

- Design system: https://claude.ai/artifact/Cyvk79v8nRck8cenN92cmR
- Screen mockups: https://claude.ai/artifact/QD59BPykasBaNm8hYv8cqU. The watch mockup predates the
  deck list and the complication; the shipped watch app is newer.

**Keep them in step:** when a token or a guideline changes, change it in the design system and
here in the same pull request, then update the CSS and run `apple/scripts/generate_tokens.py` for
token changes.
